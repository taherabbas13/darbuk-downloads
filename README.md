# دربك العراق | Darbuk Iraq

Public distribution page for signed Android app releases. This repository contains release APK files and their update manifests only; application source is kept private.

## Download

Download the current signed APK from [latest release](https://github.com/taherabbas13/darbuk-downloads/releases/latest/download/Darbuk-Android-latest.apk).

The `update.json` file attached to each release contains the version, release notes, version code, APK URL, and SHA-256 checksum used by the app's update check.

## Android Auto

The APK supports Android Auto's navigation templates and navigation intents. Google Play's trusted distribution and car app review are required to make Car App Library apps available in a real vehicle; GitHub downloads are intended for phone distribution and direct testing.
